# 设计五感 · Design Five Tones

五感不是五套模板，是同一信息结构下的五种**表达压力**：

| 调性 | English | 一句话 | 适合 |
|---|---|---|---|
| 乱 | CHAOTIC | 乱中有序的能量 | 潮流、音乐、创作者工具、青年文化 |
| 拙 | ROUGH | 拙而不劣的真诚 | 手作、自然、独立品牌、人文内容 |
| 恶 | FIERCE | 主动冒犯安全审美 | 游戏、亚文化、暗黑叙事、警示议题 |
| 精 | EXQUISITE | 毫米级的工艺感 | 奢侈品、珠宝、非遗、高客单 |
| 空 | VOID | 空是容器，不是缺失 | 科技、建筑、生活方式、高端 B2B |

**来源**：善本 SendPoints《平面设计师的风格手册》与《设计五感》系列（乱/拙/恶/精/空五章）。本 skill 在其视觉分类之上补入东西方哲学根源与可执行规则。

## 使用顺序

1. 读 brief，确定一个**主调**。
2. 最多允许一个**辅调**，占比 ≤ 20%。禁止两个主调。
3. 写下 tone statement：`主调 X · 辅调 Y(≤20%) · 强度 N/5`。
4. 把 tone statement 交给 `landing-page-design`（结构与文案）或 `design-to-motion`（动效性格）。
5. 交付前按该调性的「检查项」逐条自检。

## 选调决策

按顺序回答，先命中的规则优先：

1. **行业禁区**：金融、医疗、政务、教育低龄段 → 恶、乱禁用；拙只用于低强度人文表达。
2. **价值感知**：需要「贵、可信、克制」→ 精 或 空。
3. **受众关系**：需要「同频、叛逆、现场感」→ 乱 或 恶。
4. **产品性格**：手作、自然、独立、慢 → 拙。
5. **信息密度**：信息少、要想象空间 → 空；信息多、要能量 → 乱；信息多、要价值 → 精。
6. **仍未定**：默认 空（最安全），用 精 做局部强调。

冲突时优先级：**可读性 > 转化目标 > 品牌调性 > 装饰表达**。五感永远不覆盖无障碍红线。

## 通用红线（对所有调性生效）

- 正文对比度 ≥ 4.5:1；大字（≥ 24px bold）≥ 3:1。
- 正文不用装饰字体；行宽 45–75ch；行高 ≥ 1.5。
- 键盘焦点可见；语义结构正确；图片有 alt。
- 动效必须尊重 `prefers-reduced-motion`；频闪 ≤ 3Hz。
- 每个调性的「强度」是旋钮，不是开关：先用 2/5，确认成立再加到 4/5。

## 乱 · CHAOTIC

**定义**：用扭曲、无序、堆砌、差异制造能量和情绪。关键不是「乱」，是**乱中有序**（order within chaos）——观者能感到控制力。

**哲学根源**
- 东方：狂草（张旭、怀素）以破字形、破行气换取笔墨节奏；王冬龄「乱书」把可读性溶解为纯线条；「无法而法」。
- 西方：Action Painting / Pollock 滴画；达达拼贴；朋克 zine；Glitch、Anti-design、Maximalism、Bricolage。

**视觉特征**：多轴倾斜、重叠与裁切、扫描/复印质感、错位网格、混合字体、高密度、冲突色、噪点与故障。

**可执行规则**
- 先立 2–3 个「乱中的锚」：一条固定基线、一个主色、一个可读正文区。没有锚的乱只是噪音。
- 装饰层可乱，信息层必须稳：标题/装饰可倾斜，正文与 CTA 保持正交。
- 重叠最多 4 个层级，每层必须有明确作用；z-index 不是装饰。
- 每屏最多 3 种字体表现，正文仍用可读字体。
- 动效：错位/抖动入场可以，但每 6–8 秒必须回归一次稳定态。

**反模式**：全站所有元素都乱；正文用装饰字体；无锚点堆砌；CTA 被装饰淹没；把「加载失败」的样子当设计。

**检查项**
- [ ] 遮住装饰层，页面是否仍然读得懂？
- [ ] CTA 是否 3 秒内可见？
- [ ] 乱是否收得住（有稳定态）？

## 拙 · ROUGH

**定义**：以笨拙、粗粝、未完成感对抗过度精致。核心是**拙而不劣**——技术上的生涩，审美上的真诚。

**哲学根源**
- 东方：傅山「四宁四毋」——宁拙毋巧，宁丑毋媚，宁支离毋轻滑，宁真率毋安排；老子「大巧若拙」「见素抱朴」；文人画与民间美术；侘寂（wabi-sabi）。
- 西方：Art Brut / 原生艺术（Dubuffet）；Naive art（卢梭）；手作与 DIY；Matisse 晚期剪纸；朋克手写。

**视觉特征**：手绘线条、抖动边缘、纸/布/噪点肌理、轻微错版套色、不完美对齐、手写、胶带与订书钉、褪色。

**可执行规则**
- 缺陷必须受控且可数：每个区块最多 2 处刻意不完美（偏移、旋转 0.5–2°、手绘边框）。
- 真实材质优先于伪纹理：能实拍/手写，就不用滤镜假装。
- 拙需要呼吸：留白和慢节奏是前提，否则「拙」会变成「脏」。
- 字体：标题可用手写/木刻/打字机，正文仍用可读字体。
- 动效：手绘描边、逐帧抖动、纸张翻动；「卡顿」感最多出现 2 次。

**反模式**：所有元素都歪；用劣质字体冒充手作；纹理盖住内容；为「丑」而丑，没有真诚；把可读性当成精致来砍掉。

**检查项**
- [ ] 去掉纹理后，设计是否仍然成立？
- [ ] 不完美是否可数、可控？
- [ ] 读者第一眼感到「真」还是「糙」？

## 恶 · FIERCE

**定义**：用黑暗、攻击性、禁忌、变形制造冲击。不是「难看」，是**主动冒犯安全审美**，逼人正视。

**哲学根源**
- 东方：地狱变相与罗汉的狞厉之美；傅山「宁丑毋媚」的丑学；民俗镇煞（钟馗、傩面）。
- 西方：哥特与 Grotesque；Bakhtin 的狂欢；朋克/金属；恐怖电影（《异形》《银翼杀手》）；Brutalism；Anti-design / 新丑风。

**视觉特征**：高对比黑白、血红、尖角、破败、骨骼与液体、故障、极端字重、脏旧、密集噪点、非常规裁切。

**可执行规则**
- 冲击点集中：全站只设 1 个攻击性焦点（通常是 hero 或一个 section），其余降噪。
- 恐怖不等于恶心：优先用比例、结构、留黑制造不安，少用血腥素材。
- 可读性底线不破：正文不用血红小字、不用纯黑底反白细字；对比度 ≥ 4.5:1。
- 合规：不冒犯受保护群体；不用真实伤害影像；遵守平台内容政策；必要时加内容提示。
- 动效：硬切、故障位移可以；频闪 ≤ 3Hz 且提供减弱动效版本。

**反模式**：全站阴间；用真实血腥；为猎奇牺牲可用性；频闪无降级；把「恶」做成廉价恐怖游戏 UI。

**检查项**
- [ ] 目标受众能否接受，是否越过了品牌底线？
- [ ] 是否需要 content warning？
- [ ] CTA 与核心信息是否仍然清晰？

## 精 · EXQUISITE

**定义**：用极致工艺、细节密度和完成度建立价值感。核心是**毫米级的控制**，不是装饰的堆叠。

**哲学根源**
- 东方：工笔重彩、唐卡（造像量度、金线）、缂丝（「一寸缂丝一寸金」）、宋瓷与明式家具；「格物」。
- 西方：Art Nouveau（Mucha）、Arts & Crafts（Morris）、高级定制与钟表工艺、瑞士排版精度；「God is in the details」（Mies）。

**视觉特征**：细线、金/箔、微纹理、多重描边、精确对齐、复杂图案、高对比衬线、层次丰富但克制。

**可执行规则**
- 精度必须可验证：对齐走 4/8px 网格；线宽只用 0.5/1/2px 三档之一；同一元素不超过 2 种线宽。
- 细节预算：每屏最多 3 个高细节区，其余留白，避免视觉疲劳。
- 材质一致性：金、纸、石纹只选一种主材质语言，不混搭。
- 字体：高对比衬线 + 克制无衬线；字号阶梯精确，不出现随意值。
- 动效：慢、顺、无弹跳；遮罩揭示、描线、金属高光扫过；时长 600–1200ms。

**反模式**：细节堆满没有焦点；廉价伪金箔与俗艳渐变；对齐不精确；动效过快破坏精致感；用细节掩盖内容空洞。

**检查项**
- [ ] 放大 200% 后细节是否仍然成立？
- [ ] 每屏是否有明确视觉焦点？
- [ ] 线宽、间距、字号是否都来自同一套刻度？

## 空 · VOID

**定义**：用留白、极简、未填满的空间容纳想象。**空不是没有，是容器**——它让观者把自己的经验填进去。

**哲学根源**
- 东方：老子「凿户牖以为室，当其无，有室之用」；禅宗「空」；侘寂；间（ma）与余白；原研哉《白》《设计中的设计》——白既是全色也是无色，空是可以被填入的状态；水墨留白。
- 西方：极简主义（Agnes Martin、Donald Judd）；负空间；Mies「Less is more」；Dieter Rams「Less, but better」；瑞士国际主义。

**视觉特征**：大面积留白、低饱和或单色、极少元素、细字重、大字号、无装饰、精确的间距节奏、单一焦点。

**可执行规则**
- 留白是结构，不是剩余：先定间距系统（4/8pt），hero 区留白至少占视口 50%。
- 元素预算：每屏 ≤ 5 个信息单元；每屏 ≤ 2 种颜色（含黑白灰）。
- 层级只靠字号、间距、位置，不靠颜色和装饰。
- 字体：一个字族、2–3 个字重；行高 1.5–1.8；字重不低于 300（小字不低于 400）。
- 动效：极慢极轻；位移 ≤ 16px 或纯 fade；缓动 `cubic-bezier(0.32, 0.72, 0, 1)`；时长 500–900ms；不弹跳。

**反模式**：空到没有层级；留白不均匀；用「极简」掩盖内容缺失；细字重低对比不可读；为了空而删掉必要信息。

**检查项**
- [ ] 再删掉任意一个元素，是否反而更好？
- [ ] 留白是否有节奏（而不是随机空）？
- [ ] 正文对比度与可读性是否达标？

## 组合规则

| 组合 | 判断 |
|---|---|
| 空 + 精 | 安全且高级：空做结构，精做局部细节 |
| 拙 + 空 | 安全：手作主体 + 留白呼吸 |
| 乱 + 恶 | 高能量：适合潮流/游戏，需强锚点 |
| 精 + 恶 | 危险：工艺感与破坏感互相抵消，避免 |
| 乱 + 空 | 危险：能量与留白互相抵消，除非分区隔离 |
| 拙 + 精 | 谨慎：只在「手作主体 + 精细标签」时成立 |

辅调只用于局部强调，不进入主结构。

## 交接协议

**给 landing-page-design**
- 输出：tone statement + 每个 section 的调性与强度。
- 它负责结构、文案、转化与具体 token；本 skill 只约束「允许选择什么性格的 token」。
- 若五感规则与转化规则冲突，以 landing-page-design 为准。

**给 design-to-motion**
- 输出：motion character = 速度 / 幅度 / 节奏 / 噪声。
  - 乱：快、幅度大、有抖动，但循环内必须回到稳定帧。
  - 拙：手绘描边、逐帧感、纸张节奏。
  - 恶：硬切、故障位移、低频闪。
  - 精：慢速遮罩揭示、描线、高光扫过。
  - 空：极慢淡入、轻微位移、无弹跳。
- 它负责精确复刻与导出流程；本 skill 只决定动效性格。

## 评审模式

拿到一个设计时，按以下顺序输出：

1. 当前实际调性（可能和声称的不一致）。
2. 主调是否成立：列出 2 条成立证据、1 条最弱证据。
3. 红线检查：对比度、可读性、无障碍、合规。
4. 该调性的反模式命中项。
5. 最小修改建议：只改最影响调性成立的 1–3 处。
